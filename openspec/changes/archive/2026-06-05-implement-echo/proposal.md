## Why

`echo` is spec-only. Three capabilities — `echo-client-api`, `echo-providers`, `echo-config` —
are already canonical in `openspec/specs/` (applied via the archived `align-echo-with-pi-ai`),
the CLI is fully designed in `echo/spec/cli.md`, and the pi-ai 0.78 alignment has settled the one
load-bearing open question (stateless-Responses signature replay). But **no Rust crate exists on
disk** — `echo/` holds only spec docs. This change introduces the first implementation: the
`echo/` Cargo workspace that turns the spec into the library `voice` links and the CLI humans run.

echo is the lowest shared layer of the system: `voice` links it **in-process** for every model
call, and `implement-voice-harness` explicitly sequences itself *after* echo (its hot path —
`echo::stream`, `Context`, `Message`, `Tool`, `Usage`, `get_model` — cannot compile until echo's
crate exists). Nothing in the Aria → Harmony → Voice → echo loop can run real model traffic until
echo is built. Building it now unblocks the whole stack.

## What Changes

- **New `echo/` Rust workspace** — `crates/core` (library crate `echo`) + `crates/cli` (binary
  `echo`), edition 2024. Greenfield: despite the README's "older OCaml scaffold" note, **no
  OCaml/dune tree exists on disk** — there is nothing to migrate or delete.
- **Implement `echo-client-api`** — `Context`/`Message`/`Block`/`Tool`/`Model`/`Options` types;
  `stream` (native) and `complete` (thin collector); the streaming event union with stable
  `content_index`; `Usage`/`Cost` with distinct `cache_write` vs `cache_read`; signature
  preserve-and-replay (incl. `Thinking.redacted`); thinking-level clamp; bounded retry with a
  `max_retry_delay` fail-fast cap; the `is_context_overflow` predicate; abort handling.
- **Implement `echo-providers`** — the `Api × Provider` factoring; the **open `ApiProvider`
  registry** (`register_api_provider`/`get_api_provider`); the three v1 adapters
  (`anthropic-messages`, `openai-responses`/`openai-completions`, `openai-codex-responses`);
  the per-provider compat struct (data-not-adapter quirks); streaming→event mapping with
  non-streaming simulation; tool mapping; Anthropic prompt caching reflected in `Usage`;
  credential resolution order that **fails before any network I/O**.
- **Implement `echo-config`** — env-first credential resolution; `~/.config/echo/config.toml`
  (`chmod 600`, refuse world-readable, `ECHO_CONFIG` override); the OAuth token store under
  `~/.config/echo/tokens/<provider>.json` (`chmod 600`, auto-refresh before expiry); the env-var
  table; secret redaction in `config show`. No in-echo sops/decryption (deferred, unchanged).
- **New `echo-cli` capability + implementation** — `echo run` (one-shot: `Context` JSON on stdin
  → `score.echo-event/v1` JSONL on stdout), `--json`/`--complete` collector mode, `echo repl`
  (ephemeral in-memory test loop), `echo login`/`logout` (OAuth), `echo providers`, `echo config
  show`. **stdout carries only protocol bytes; stderr carries logs.** echo is stateless across
  invocations.
- **Generate the model registry** — the `Model` pricing/limits/thinking-level table from a
  pricing source, exposed through `get_model`/`get_models`/`get_providers`/`calculate_cost`/
  `clamp_thinking_level`. v1 uses a **vendored snapshot regenerated by a committed script**
  (see `design.md`).
- **Honor `score.echo-event/v1` fidelity** — the CLI's JSONL serialisation stays faithful to the
  Rust event union (`CONTRACT.md` → "Voice ↔ echo").

Out of scope (per `BACKLOG.md` / `spec/providers.md`): providers beyond the v1 trio
(DeepSeek/local/OpenAI-compatible, Google/Vertex, Bedrock, OpenRouter, …), Anthropic
subscription OAuth, and the sops-encrypted secrets rung + `echo secret-edit` — all deferred and
landed later as metadata-plus-compat or a follow-up change, not new adapters here.

## Capabilities

### New Capabilities
- `echo-cli`: The `echo` binary's contract — the `run`/`repl`/`login`/`logout`/`providers`/
  `config show` command surface, the one-shot stdin-`Context`-JSON → stdout-`score.echo-event/v1`-
  JSONL discipline (stderr = logs only), `--json`/`--complete` collector mode, REPL ephemerality,
  and statelessness across invocations. It **references** the `echo-client-api` event/usage union
  rather than redefining it.

## Impact

- **New code**: `echo/Cargo.toml` (workspace), `echo/crates/core/` (lib `echo`),
  `echo/crates/cli/` (bin `echo`). Adds `echo/.gitignore` for build artifacts.
- **Dependencies** (exact crates pinned in `design.md`): an async runtime (`tokio`), a streaming
  HTTP client + SSE parser (`reqwest`/`eventsource`-style), `serde`/`serde_json`, a `Stream`/
  `async-stream` mechanism for `EventStream`, a TOML parser, an OAuth2 + PKCE flow for the token
  store, and a readline crate for the REPL.
- **Downstream**: `voice` links `echo` as a path dependency (`../echo`) — this change **clears
  `implement-voice-harness`'s prerequisite gate** (its task 1.1). Aria's available-models
  inventory is sourced from `get_models` (`CONTRACT.md`). Harmony does not call echo in v1.
- **Contract**: `CONTRACT.md` "Voice ↔ echo" is the **fidelity target**, not an edit target —
  `score.echo-event/v1` JSONL must match the implemented Rust event union. No wire-format change,
  so **no `CONTRACT.md` edits are required** by this change.
- **Spec docs**: the five `echo/spec/*.md` files become the implemented contract; the four
  "Deferred work" `BACKLOG.md` items (Rust rescaffold, v1 providers, the CLI, JSONL fidelity) are
  ticked as they land.
- **Security surfaces realised**: URL-image SSRF bound by timeout + max size; `chmod 600` on
  config and token files (refuse world-readable); credential material never logged and redacted
  in `config show`.
